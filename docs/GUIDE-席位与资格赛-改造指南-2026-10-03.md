## 1. 目标数据流

```
K甲 赛段收官（春 / 夏）
   ↓ 产出该赛段名次：champion / runnerUp / third / fourth
KPL 赛季切换时结算 2 个临时席位：
   ├─ K甲 该赛段冠军（过审）      → 直授 1 个临时席位
   └─ 资格赛（4 晋 1 / 3 晋 1 / 2 晋 1）→ 另 1 个临时席位
        参赛：上届 KPL 2 支临时席位俱乐部 + K甲 亚军 + 季军（未过审顺延至殿军）
   ↓ 例外：上届临时席位俱乐部夺得刚结束那届 KPL 冠军
        → 该队直接保留 + 【取消该届资格赛选拔】→ 两席 = 夺冠队 + K甲冠军
   ↓
写回 newSeats（16 固定 + 2 临时）→ AI_TEAMS / AI_ROSTERS / s.leagueTeams 单一真相源
   ↓
玩家未获席位 → 出口（§8 开关：回 K甲 参赛 / 待业再就业）
```

## 2. 权威规则速查（实现时照这张表，别凭记忆）

### 2.1 两个席位的来源

| 席位 | 来源 | 备注 |
|---|---|---|
| 1 | **K甲 该赛段冠军**（资格审核通过后**直授**） | 冠、亚军均未过审时 → 下届有 **2 个**晋升名额（都走资格赛） |
| 2 | **资格赛 1 个名额**（胜败组淘汰赛） | 上届 2 支 KPL 临时席位俱乐部 + K甲 亚军、季军 |

### 2.2 资格赛分档（权威）

| 情形 | 赛制 |
|---|---|
| K甲冠军过审 → 1 个名额；**2 支** K甲 过审 | **4 晋 1 胜败组淘汰赛**（BO7 · 全局 BP · 败方选边 · 巅峰对决 · **3 个比赛日**） |
| K甲冠军过审 → 1 个名额；**仅 1 支** K甲 过审（亚/季/殿军顺延后） | **3 晋 1 单循环积分赛 BO7**，排名第一获席位 |
| K甲冠亚军均未过审 → 2 个名额；**1 支** K甲 过审 | **2 晋 1 单场 BO7** |
| K甲冠亚军均未过审 → 2 个名额；**2 支** K甲 过审 | **3 晋 1**（1 支 KPL 临时席位俱乐部 + 2 支 K甲） |
| 任意 | **递延**：亚/季军未过审 → 名额至多顺延至**殿军** |

### 2.3 夺冠例外（权威，出处见 RULES §3）

> 「如KPL临时席位队伍获得本届KPL冠军，将直接获得下届临时席位，同时取消下届KPL临时席位资格赛选拔。」
> （《K甲夏季赛赛事规则》§4.5.2 · 1.(3)；2024/2025/2026 三版逐字相同）

**推导结论（= 甲）**：两席 = **夺冠的临时席位队** + **K甲冠军**；上届另一支临时席位俱乐部**失去参赛资格**（没有产生授予它的途径，不是"垫底被收回"）。

### 2.4 赛段映射（**关键，别做错**）

| K甲 赛段 | 决定哪个 KPL 赛季的临时席位 |
|---|---|
| **K甲 春季赛** 的结果 | 当年 **KPL 夏季赛** 的临时席位 |
| **K甲 夏季赛** 的结果 | **次年 KPL 春季赛** 的临时席位 |

出处：`kgl_rules2026.txt:655`「2026年K甲**夏季赛**决赛冠军……将获得 **2027年KPL春季**临时席位资格赛参赛资格」。

> ⚠️ **这修正了我早前的一处判断**：资格赛的输入是**刚结束那个 K甲 赛段**的名次（`kjiaRank` 现成的per-split 排名），**不是年度累计排名**。所以 K甲 Level 1 **不需要**改成"年度赛季"，只需要"队伍身份与战力跨赛段连续 + 每赛段独立收官记录"。

### 4.1 `src/js/kjia.js` — K甲 Level 1（**先做，资格赛的地基**）

**目标**：队伍身份与战力跨赛段连续；每赛段独立收官并留档。

```js

const KJIA_AI_TEAMS = [
  { name:'石家庄WLT', power0:372, growth:1.00 },
  // …（真实 12 队名单见 RULES §4；先上 7~12 支都行，但**必须固定**）
];

// ② 从 K甲 全局状态里取"本届 K甲 的 AI 队战力"，而不是每次重掷
function kjiaAiPower(s, name){
  const k = ensureKjia(s);
  const base = (KJIA_AI_TEAMS.find(t=>t.name===name)||{}).power0 || 350;
  const yrs = Math.max(0, (s.season||1) - (k.baseSeason||s.season||1));
  return Math.round(base * (1 + 0.01*yrs));   // 逐年演化（系数按你的平衡口径调）
}

// ③ initKjia：保留 squad 与 seatHistory，**不再重掷 powers**
function initKjia(s){
  const prev = s.kjia || {};
  // …建 teams/rounds/tables（沿用现有舍转法单循环）…
  s.kjia = { teams, powers, rounds, rd:0, day:0, tables, results:[], squad: prev.squad || buildSquad(s),
             champ:null, my:kjiaMyName(s), baseSeason: prev.baseSeason || (s.season||1),
             seatHistory: prev.seatHistory || [] };
}

// ④ finishKjiaSplit：收官时留档名次（资格赛的输入）
function finishKjiaSplit(s){
  const k = ensureKjia(s); if(!k || k.champ) return;
  const rank = kjiaRank(s);                    // 现有函数即可
  k.champ   = rank[0];
  k.runnerUp= rank[1];
  k.third   = rank[2];
  k.fourth  = rank[3];
  k.seatHistory.unshift({ year: gameYear(s), split: s.split, champion:k.champ,
                          runnerUp:k.runnerUp, third:k.third });
  k.seatHistory = k.seatHistory.slice(0, 6);
  // …现有奖金/粉丝/士气逻辑保留…
}
```

**验收**：连续 3 年同一存档 → 7 支 AI 队**身份不变**、战力**单调演化无重掷跳变**；每赛段 `finishKjiaSplit` 后 `seatHistory` 有该赛段名次。

> 出处依据：`kjia.js:37` 现在每赛段 `rnd(360,392)`，导致"K甲冠军"是随机抽签；而 KPL 临时席位直授就取这个冠军。

### 4.3 `src/js/rules.js` — `settleTempSeats` 重写

**签名建议**：`settleTempSeats(s, opts)`，`opts = { kglSplitResult, triggeredBy:'split'|'season' }`。

```js
function settleTempSeats(s, opts){
  if(!s) return;
  initTempSeats(s);
  const curSeason = s.season || 1;
  s.tempSeatFixedExpiry = s.tempSeatFixedExpiry || {};

  // ① 清理过期保留（一季化；老档无 expiry 视为已过期——现有实现保留）
  s.tempSeatFixed = (s.tempSeatFixed||[]).filter(t => (s.tempSeatFixedExpiry[t]||0) >= curSeason);

  // ② 夺冠判定：**刚结束那届** KPL 冠军（用 split/season 双重过滤，别用 titleHistory 上的标记）
  const champTeams = (s.titleHistory||[])
    .filter(t => t && t.champ && isTempSeat(s, t.champ) && !isFixedSeatTeam(t.champ)
              && (t.season == null || t.season === curSeason))
    .map(t => t.champ);
  const protectedSeats = [...new Set(champTeams)];
  protectedSeats.forEach(t => {
    s.tempSeatFixedExpiry[t] = curSeason;
    if(s.tempSeatFixed.indexOf(t) < 0) s.tempSeatFixed.push(t);
  });

  // ③ 决定 2 个席位的归属
  let awards = [];
  if(protectedSeats.length){                       // 例外：夺冠保留 → 资格赛取消
    awards = protectedSeats.slice(0, TEMP_SEAT_COUNT);
    const kglChamp = (opts.kglSplitResult||{}).champion;
    if(kglChamp && awards.length < TEMP_SEAT_COUNT) awards.push(kglChamp);
    cancelSeatPlayoff(s);                          // 明确记录"本届资格赛取消"
  }else{                                           // 常态：K甲冠军直授 + 资格赛 1 席
    const kglChamp = (opts.kglSplitResult||{}).champion;
    if(kglChamp) awards.push(kglChamp);
    const po = runSeatPlayoff(s, opts.kglSplitResult);   // seatplayoff.js
    (po.winner||[]).forEach(n => { if(awards.length < TEMP_SEAT_COUNT) awards.push(n); });
  }

  // ④ 到期：上届临时席位里**未获授予**的俱乐部失去参赛资格
  const expired = (s.tempSeats||[]).filter(t => awards.indexOf(t) < 0);
  s.tempSeats = awards.slice(0, TEMP_SEAT_COUNT);
  // 兜底补齐（防御性：不足 2 席时从 K甲 顺延，别让联盟少队）
  while(s.tempSeats.length < TEMP_SEAT_COUNT){ /* 从 kglSplitResult 亚/季/殿军顺延，或 KJIA pool */ }

  if(expired.indexOf(s.teamName) >= 0 && awards.indexOf(s.teamName) < 0){
    s.seatLost = true;
    s.seatLostReason = (s.seatPlayoff && !s.seatPlayoff.cancelled) ? 'tempSeatPlayoffLost' : 'tempSeatExpired';
  }

  // ⑤ 写回：**单一真相源**（现有实现保留，勿退回三段各自演算）
  const newSeats = [...FIXED_SEAT_TEAMS, ...s.tempSeats];
  //   AI_TEAMS := newSeats 对应对象（保序复用；AI_TEAMS 含玩家队——`initGroups` 自己会 filter）
  //   AI_ROSTERS := 只留 newSeats；新进队用旧队阵容克隆
  //   s.leagueTeams := newSeats（若 seatLost 则剔除玩家队，长度 17）
  writeSeats(s, newSeats);

  // ⑥ 日志/文案（见 §5）
}
```
