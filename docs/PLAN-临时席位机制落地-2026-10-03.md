## 2. 目标规则与机制

### 2.1 一句话规格

> 固定 16 席永不降级；2 个临时席每赛季重新授予：**本季夺冠的临时席队保留其席位**（非转正固定席，次年须再夺冠）。
> 其余临时席位：**若当年存在夺冠保留** → **席位赛取消**，空缺席位**直授 K甲冠军**；
> **若当年无夺冠保留** → **举办席位赛**，由**上季临时席球队 + K甲 年度前 N** 争夺 2 个席位；
> **未获授予的旧临时席球队失去 KPL 参赛权限**（不是"因垫底被收回"）。

### 2.2 状态机（每年年结一次）

```
读 titleHistory（当前年 · 临时席队 · champ）
├─ 有夺冠保留 → protected = 夺冠队；vacancy = 2 - |protected|
│    └─ vacancy > 0 → 【席位赛取消】空缺直授 K甲年度冠军（次席顺延 K甲亚军）
└─ 无夺冠保留 → vacancy = 2 → 【举办席位赛】
     ├─ 参赛：上届 2 支 KPL 临时席位战队 + K甲 亚军 + K甲 季军（资质未过由殿军顺延）
     ├─ 赛制：小规模（BO7 单败 / 小组循环，2~3 天赛程）
     └─ 产出：2 个席位获得者（含玩家能否保级）
↓
非获授予的旧临时席队 → 到期（失去参赛权）
↓
写回 newSeats（16 固定 + tempSeats）→ AI_TEAMS / AI_ROSTERS / s.leagueTeams 同构
↓
玩家在"未获授予"集合 → s.seatLost=true（走 D3 出口）
```

### 2.3 数据模型

| 字段 | 目标 |
|---|---|
| `s.tempSeats` | 不变：本季持有临时席的队（2 支） |
| `s.tempSeatFixed` / `s.tempSeatFixedExpiry` | 保持字符串数组 + 旁路 expiry（一季化） |
| `s.seatLostReason` | **新增**：`'tempSeatPlayoffLost' \| 'tempSeatExpired' \| 'historicalRelegation'`，供文案/UI 区分 |
| `s.seatPlayoff` | **新增**：`{year, teams, rounds, bracket, winner:[...], done}` |
| `s.kjia` | Level 1 后新增跨季字段：`seasonChamp`、`annualRank`、`history`；AI 队加 `def{power0,growth}` |

**状态纯度（必做）**：现实现把机制标记 `t._seatProtected` 写在 **`titleHistory` 条目**上（`rules.js:64/67`）——拿历史记录当状态载体，历史一旦迁移/裁剪/重建，夺冠保护会**静默丢失**。改为只存 `tempSeatFixedExpiry`（+ 可选 `s.seatProtectLog` 供审计），`titleHistory` 保持只读。

### 2.4 席位赛机制规格（**已按权威条文定稿**）

## 2.5 K甲 重做分级评估（回答"K甲是不是也要重做"）

### 现状（实读 `src/js/kjia.js`，260 行）

- 8 队 = 7 支**虚构** AI 队（`K甲·苍穹/星火/沧澜/曜石/铁鳞/游隼/雾嶂`）+ 玩家二队；单循环 7 轮、每 2 天一轮；
- **每个赛段（春/夏）重开一届**（`initKjia` 由 `startSplit` 调用），且 7 队战力**每次重掷**：`kjia.js:37` `i<3?rnd(360,392):rnd(328,388)` → **球队没有身份连续性、没有历史战绩，冠军基本是每半年的随机抽签**；
- 实质是**玩家二队培养通道**（下放 `sendKjia` / 上调 `promoteKjiaPlayer` / 归队成长），这部分设计完整且已修过峰值漏洞（`kjiaGrantReturnGrowth` 受 `p.peak` 约束）——**建议保留不动**；
- `s.kjia.champ` 被 KPL 临时席位机制**直接当作"K甲冠军"**使用（`rules.js:108-118`）。

### 分级结论

| 级别 | 内容 | 是否本次必做 | 理由 |
|---|---|---|---|
| **Level 1** | **跨季连续性**：AI 队固定身份 + 战力按赛季演化（不再每赛段重掷）；**保留每赛段独立收官并留档**（冠军/亚军/季军 → `seatHistory`）；**不需要**改成年度排名 | **必做** | 资格赛的输入是**刚结束那个 K甲 赛段**的名次（`kgl_rules2026.txt:655`），而当前名次是每赛段重掷的随机数 →"无冠军打席位赛"会变成"和随机数打" |
| **Level 2** | **真实名录 + 真实赛制**：把虚构队名换成**真实 K甲 12 支战队**，补「春/夏双赛季 + 常规赛 BO5 双循环 + 季后赛 8 队 BO7 双败 + K甲 自身升降级资格赛（3 进 2）」 | 延后（D7） | 属史实专项，与 2017 年档名录同类；**权威目标已取到**（`docs/RULES-席位与K甲-权威依据-2026-10-03.md` §4），做完再做不返工 |
| **Level 2b** | **常规赛编组改为权威规则**：按上届最终排名分桶（1-6/7-12/13-18）抽签分三组各 6 支；临时席队参与过上届则正常排名，未参与视为 13-18 名 | 延后（待 owner 确认为有意简化还是遗漏） | 权威条文见 RULES 文档 §5。当前实现是按战力蛇形分组——改动会影响分组/赛程/平衡门禁，不能顺手做 |
| **Level 3** | 席位赛机制本身（§2.4） | 必做 | D1 拍板后的主体 |

**依赖链：Level 1 → 席位赛（Level 3）→ Level 2（可选）**。三者不要混做，否则验证无法归因。

### Level 1 具体改法

```js
// kjia.js —— 见改造指南 §4.1（细则与伪代码）
// 1) AI 队固定身份与基线（不再每次 rnd）

// 2) 战力按"距基准赛季的年数"演化，而不是每赛段重掷
function kjiaAiPower(s,name){ /* power0 * (1 + 0.01*年数) */ }
// 3) initKjia：保留 squad / seatHistory / baseSeason，不再重掷 powers
// 4) finishKjiaSplit：每赛段收官时留档 champion / runnerUp / third / fourth + seatHistory
```

**验收**：同一存档连续跑 3 年，`s.kjia` 的 AI 队**身份不变**、战力**单调演化无重掷跳变**；每赛段名次可复现并留档 `seatHistory`；`initKjia` 不再重掷 `powers`。
