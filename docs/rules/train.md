## 硬数值

| 项 | 值 |
|---|---|
| 全队训练费用 | 13 万/次（属性 +1~2，受 form/天花板） |
| 英雄特训费用 | 25 万/次 |
| 每日限制 | 全队 `S.trained` 一次；选手模式另有 `socialUsed` |
| 青训营 | 每日培养名额与训练共享口径；晋升门槛四维总和约 300 |
| 自留签 | 每季约 2 个晋升名额（见 draft/main 相关字段） |

## 隐性规则

1. **`trainBlockedReason`**：伤停 / 租借在外 / K甲 / 国家队集训 → 不能加练（三身份同一套）。  
2. **收益走 `trainOutcome`**（playerops）：状态低迷常 0；贴 `peak` 只维持。  
3. **训练略伤士气**（约 −2），休息回体力并加速养伤（−2 伤天）。  
4. **青训晋升**受 `rosterGuard` / `canSign`：名单满不能提拔。  
5. **17 岁**可培养，**满 18** 才能进首发出场。  
6. 转会期「跳过剩余天数」会自动训练/青训培养（有支出），不是白跳。  

## 易踩坑

- 士气/体力影响 `playerPower` → 教练排首发；只加练不休息可能一直上不了场  
- 青训名字与一队/市场全局查重（`rookieUsedNames`）
