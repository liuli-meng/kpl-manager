## 隐性规则

1. **选手唯一评价 = `overall()`**，无稀有度标签；身价/周薪/市场档位都从 OVR 曲线出。  
2. **脚本 `base` 是真实评级**（明星手写高 base），不是「生成后再调」。  
3. **视觉哈希确定性**：同 id/名字永远同队徽/头像/英雄图标，便于离线单文件。  
4. **`SCENARIOS` 开局剧本**改的是开局资源/阵容/士气，**不改**转会费封顶、顶薪、名单上限等全局硬规则。  
5. **成就表 `ACHIEVEMENTS`** 由赛季/经营钩子解年份；`s.achieved` 只记 id→年，文案不进存档。  
6. **事件池 `EVENTS`** 的 `{p}` 必须与 `fn(s,p)` 作用同一选手（`nextDay` 里先 pick 再替换）。

## 易踩坑

- 改 `VALUE_PTS` / `WAGE_PTS` 会牵动转会报价、AI 预算、剧本诊断日志，要跑经济相关 verify  
- 新脚本/明星 def 要保证 **联盟内 id 唯一**；名字池耗尽走音节生成（见 verify-names）  
- 版本热门英雄 `hot` 只影响战力，不自动改身价
