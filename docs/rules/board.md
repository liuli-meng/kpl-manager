## 隐性规则

1. **信任度** 0–100；按赛季 KPI 达成增减；连续未达标警告，归零 **解约**。  
2. **KPI**：首年按分组（S 前4 / A 前8 / B 前12 一类口径）；之后看上年年度积分名次。  
3. **解约是软终局**：`board.fired` 时 **UI 入口** `uiGuard` 拦截推进/开赛/杯赛；**引擎 `nextDay` 仍可被门禁调用**（故意不破坏平衡模拟）。  
4. 干预：低信任可能砍工资帽；高信任可能发钱（以源码事件为准）。  
5. 选手生涯模式不触发经理董事会终局逻辑时，要以 mode 守卫为准。
