## 赛历顺序（摘要）

春季赛 → 挑战者杯 → EWC → 夏季赛 →（亚运年）亚运会 → KPL 年度总决赛  

| 赛事 | 要点 |
|---|---|
| 挑战者杯 | 含 K甲/资格赛队伍；与联赛并行的杯赛结构 |
| EWC | 海外队池；擂台/淘汰以源码 bracket 为准 |
| 亚运会 | 四年一届量级；国家队征召，玩家不直接执教国家队 |
| 年总 | 年度积分晋级；大师组/精英组替补轮换规则（见年总相关测试） |

## 隐性规则

1. **玩家杯赛可自动赛**（选手模式）或走 BP；结果写回 bracket，**真相源不是 UI**。  
2. **亚运**：麾下入选选手缺席夏赛，赛后按奖牌档回流人气/身价/士气；协会奖金；年总开局体力不满。  
3. **最强对手**设定在国家队线为韩国（难度/名单见 cups 常量）。  
4. **FMVP**：冠军队总决赛局内 MVP 累计；进荣誉室并给人气/身价。  
5. **结构丢失**：读档若 phase 有、bracket 无 → migrate 尝试重建 setup 或回退 phase（防死锁）。  
6. **玩家模式年总**可能有强制轮换/全员出场要求，不满则士气处罚（大师组）。  

## 易踩坑

- 杯赛与常规赛 phase 切换靠 `advanceCalendar` / cup step，按钮入口要与 `nextAction` 对齐  
- 时代档安装会替换联盟成员，杯赛名单生成要重算
