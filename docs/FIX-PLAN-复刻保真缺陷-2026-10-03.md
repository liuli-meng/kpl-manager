## 2. FIX-G【口径已定 · 待实现】临时席位授予机制

### 2.1 规则（owner 口径，以此为准）

- 固定 16 席**永不降级**；临时 2 席是**单赛季授权**。
- 临时席球队**夺冠** → 保留该席位（免打席位赛），**非转正固定席**；每年须重新夺冠方可续留。
- 出现「夺冠保留」时，**席位赛取消**，腾出的临时席位**直接授予 K甲冠军**；上赛季占据该席位的临时席球队**不再拥有 KPL 参赛权限**。
- **它不是"因成绩垫底被收回"**——成绩不参与这个判定。

> 结论：早稿的现象描述（"另一支无论多好都必然离开"）是对的，但**归因与文案全错**，且代码用了一个编造的判据（临时席内部积分最低者）去实现一个与积分无关的机制。

### 2.3 改法（骨架）

```js
// rules.js  settleTempSeats(s)
// ① 保留判定：保持不动（本季夺冠的临时席队 → tempSeatFixed + expiry=curSeason）
// ② 【替换】到期判定：删掉"积分最低者"评选，改为"未夺冠的临时席全部到期"
const protectedSeats = s.tempSeats.filter(t => s.tempSeatFixed.indexOf(t) >= 0);
const expired        = s.tempSeats.filter(t => s.tempSeatFixed.indexOf(t) < 0);
s.tempSeats = protectedSeats.slice();                 // 未夺冠者不再拥有参赛权限
if (expired.indexOf(s.teamName) >= 0) s.seatLost = true;   // 玩家 → 临时席位到期（口径：非"垫底"）
// ③ 空缺席位直授 K甲：保持现有机制（s.kjia.champ → kjiaRank 依序 → KJIA_AI_TEAMS 兜底）
//    注意：有夺冠保留时"席位赛取消"，所以这里是直授，**不引入任何积分比较**
while (s.tempSeats.length < TEMP_SEAT_COUNT) { /* 现有 incoming 选取逻辑 */ }
// ④ 写回：newSeats 单一真相源（保持不动）
```

**同时删除**：`worst` / `worstPts` 概念、`while (s.tempSeats.length > TEMP_SEAT_COUNT)` 的积分裁剪、`seats.forEach(... p<worstPts ...)` 评选块、`if (worst === s.teamName)` 分支。
> 纪律：**加完要删旧的**——本轮 4 个 bug 里有 2 个是"只加不删"造成的（重复调用、死代码保护分支）。

### 2.6 唯一待确认（阻塞点）

**无人夺冠的年份**，上赛季两支临时席球队怎么处理？

- **(i) 也全部到期**，两个席位直授 K甲冠亚军；
