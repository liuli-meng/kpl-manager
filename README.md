## 已知限制（产品特性，非 bug）

- **存档存浏览器 localStorage**：换浏览器、清缓存、无痕模式都会丢进度。备份方式（存档管理面板）：**「下载存档文件」存成 .json**（推荐，跨设备恢复就用它）或「复制导出」得到存档代码文本。恢复：**「从文件导入」**选本地 .json，或粘贴代码后「导入」，覆盖当前槽。
- **存档版本兼容**：存档自带 `v` 版本字段，游戏内置迁移链（`MIGRATIONS`）——旧档读入自动升级结构，未来字段变更不弃档；比当前游戏更新的存档（v 更高）会拒绝导入并提示先更新游戏。
- **赛季自动备份**：每完成一个赛季自动把上赛季末状态存入备份槽；存档管理面板可「恢复赛季备份」（恢复前当前进度也先留一份）——误触重置/存档损坏最多回滚一个赛季。
- **PWA 离线可玩**（在线版）：GitHub Pages 为 https，浏览器注册 service worker 后可安装到手机/桌面、断网可玩；`file://` 双击场景自动跳过，单文件玩法不受影响。
- **无云端存档**：纯本地单机游戏，不做账号、不联网、不上传任何数据；跨设备同步不在本项目范围（用存档文件手动搬运）。
- **单机无网络请求**：游戏运行期间不发任何网络请求，无埋点、无遥测。

## 开发：构建 / 测试（npm 一键）

```powershell
npm run build     # 把 src/ 拼成单文件 game.html（等价于 powershell -File build.ps1）
npm test          # 静态审计 + 历史 bug 回归 + 冒烟 + 平衡门禁（约 1 分钟，日常必跑）
npm run fuzz      # 模糊压测：15 赛季随机操作 + 不变量断言（约 1-2 分钟，改转会/比赛逻辑后跑）
npm run sim       # 蒙特卡洛：三档开局 ×200 赛季，看进季后赛率/夺冠率/破产率（约 2 分钟）
npm run sim:quick # 单独重跑平衡门禁（--n=150 可加大样本校准区间）
```

### 平衡门禁（CI 防漂移）

`tests/sim-quick.js` 挂在 `npm test` 末尾（约 15 秒）：三档开局 + **2017 时代档**各 30 赛季，关键比率越界即失败——

| 探针 | 断言 | 校准值（sim.js ×200） |
|---|---|---|
| 自建新队 | 季后赛率 12%~50% | ~25% |
| AG豪门 | 夺冠率 ≤88% | ~74% |
| UUG弱旅 | 季后赛率 ≤70% | ~32% |
| 三档 | 破产率 ≤6% | ~0% |
| 2017 时代（扮演 AG） | QGhappy 夺冠占比 ≤62% · 冠军多样性 ≥2 支 · 时代档季后赛 ≥35% | QG ~35%，多样性 6-11 支 |

区间按校准值 ±3σ(n=30) 设置：拦的是**结构性漂移**（新系统把数值顶穿/打崩），容忍抽样抖动。

**固定随机种子（2026-09 起）**：门禁默认用固定种子 `999983`（mulberry32 注入沙箱 `Math.random`，与 `fuzz.js` 同一实现）——同一份代码永远得到同一批数据，**CI 不会再有"随机红灯"**。此前同一份代码两次自建新队季后赛率可差 17% vs 43%：n=30 的抽样方差就是这么大，很容易被误判成"自己改坏了"。`--seed=random` 恢复随机抽样（排查用），`--n=150` 加大样本收紧区间。

**改数值后怎么校准**：`npm run sim:quick -- --n=150 --seed=random` 看新中值 → 更新上表 → 用 `--seed=<整数>` 扫 5-6 个种子，挑四个比率都最接近中位数的那个作为新的 `DEFAULT_SEED`（写在 `tests/sim-quick.js` 顶部）。固定种子下"越界重跑一次"没有意义，已自动关闭（仅 `--seed=random` 时保留）。

**覆盖范围（重要）**：`sim.js` / `sim-quick.js` 只驱动到当前赛段的 `champion` 就停（单赛段模拟），**不跑挑战者杯 / 亚运 / 年总、也不触发董事会结算**——年终类系统（董事会 KPI、年度积分、圣龙杯）不在平衡门禁覆盖内，改这些要靠 `tests/verify-*.js` 的定向用例兜。

## 年度赛历（2026 赛制）

`春 → 挑战者杯 → EWC 电竞世界杯 → 夏 →（亚运年：国家队征召 + 名古屋亚运会）→ KPL 年度总决赛 → 圣龙杯`。

**亚运会（四年一届，2026/2030/…）**：亚运年中国代表队由 KPL 各位置当季最强组成（含玩家队选手）。征召在**夏季赛开始时**宣布——入选选手整个夏季赛在国家队集训/出征，**缺席俱乐部所有比赛**。俱乐部损失核心战力，顶位策略：**队内同位置替补择优自动顶上；没有替补则位置空缺，开赛被拦截**（转会市场签替补 / 训练页提拔青训，二选一）——旧版「凭空生成青训借调」已移除，**替补深度成为亚运年的正式策略储备**。`swapPlayer` / `openSellNego` / `releasePlayer` 在集训期全部拦截（含旧档 natFill 残留）。亚运收官：征召选手归队，按奖牌档（金/银/铜/无）回流人气+8/5/3/1 与身价+6/4/2/0 与士气，协会发奖金（金 400/银 200/铜 100/无 50，按入选人数折算），年总开打时归队选手体力-15（次年新赛季由 `newSeason` 重置回满）。如果你的王牌被国家队抢走而没有替补，夏季赛真的只能 4 个人打不了——这是策略代价。

`newSeason` 同步清空上届 `agDone / ag / natSquad / natCampIds / natAnnounced`（`agDone` 不重置会导致后续亚运年不触发）。

合同改为可谈判：`openRenewNego` 选择年限（1-4 年）+ 报价（按经纪人心理价位博弈，长约溢价 / 老将抬价 / 三轮谈崩伤士气）；最后一年可提前谈，亚运集训期间不能转让/出售。

## KPL BP 赛制（已按官方规则实现）

每局 18 手，两段式征召：

| 阶段 | 顺序 |
|---|---|
| ① 第一轮 BAN | 蓝1 → 红1 → 蓝1 → 红1（各2个） |
| ② 第一轮 PICK | 蓝1 → 红2 → 蓝2 → 红1（各3人） |
| ③ 第二轮 BAN | 红1 → 蓝1 → 红1 → 蓝1（再各2，共4） |
| ④ 第二轮 PICK | 红1 → 蓝2 → 红1（各2，满5人） |

- 系列赛全局 BP：己方用过的英雄本系列赛不能再选
- BO7 战至 3:3 进第 7 局「巅峰对决」：无 BAN、双方盲选、不受全局 BP 限制
- 第 2-6 局败方选边；蓝方先 ban 先选，红方后手 counter（+2% 战力）

## 比赛流程：转会期 → 赛前准备 → BP → 比赛

**赛前转会期（开局/每个新赛季先组队，再开赛）**：创建战队或开启新赛季后先进 **7 天转会期**——落地页就是转会市场，可买断其他俱乐部选手、直签自由球员、挂牌出售、谈判教练；转会期内市场刷新免费（每日首次）、顶星（总值 90+）供给增加，每天可训练/休息后推进一天。俱乐部页显示转会期面板（倒计时 + 首发预览），**转会期内不能开赛**；天数用完自动开始联赛，也可随时点「结束转会期 · 开始赛季」提前开打。转会期结束会校验五个位置都有人（缺人会拦截）。

**卖人也是谈判（与买方对称）**：点「💰 出售」不再是一口价秒卖，而是开启竞价谈判——按总值/人气生成 1~3 家意向俱乐部（豪门预算更足），各自开价；你可以接受、逐轮递交心理要价（要价≤预算即成交、接近预算给最终报价、太高吓跑买家），三轮定生死；黄金期溢价、临近退役打折、人气加成。「回收商」按原一口价永远兜底，低总值选手无人问津也能清仓。挂牌等 AI 报价的被动路径保留。**转售保护**：所有买入路径（自由市场/买断谈判/直签）都会记录买入价，新援打满 5 场比赛前，卖方报价被压在买入价九折内——低买高卖的倒卖套利必亏，让他上场才能卖出真实身价。

**身价随比赛表现浮动**：每局为全体首发生成 KDA（胜负修正），滚动计入表现系数（EMA，均衡值=100×近期平均表现，区间 70%~150%，MVP 额外 +3）。表现系数直接乘进身价——🔥火热最高 +50%、❄️低迷最低 -30%，选手卡/阵容页总身价/选手档案/卖方谈判全部实时显示；档案还记录出场数与场均 KDA。低买练级高卖成为正式玩法：淘新人→让他打出生价→高价出售。

**赛前准备（每场比赛前）**：点开赛先弹赛前准备——调整首发（同位置换替补）、查看对手情报（各位置最强点=🔥，BAN 优先目标）、赛前预估胜率；确认后进 BP 台。BP 台内可「⇄ 换替补」不打断进度，英雄池耗尽也直接换人不用退出。

**有效战力结算（BP 决定胜负的核心）**：比赛模拟不再只吃面板战力，BP 每一步都折算进双方有效战力，BP 台顶部实时显示双方有效战力与预测胜率：

- 我方 BAN 掉「对方池内英雄」每个 **-2%**（BAN 空气仅 -0.5%，别乱 BAN）
- 对方 BAN 我方首发池内英雄每个我方 **-1%**（叠加被迫换人的熟练度损失）
- 对方每选一个版本强势（🔥）英雄 +2%（我方由英雄加成内置）
- 红方后手 counter +2%；巅峰对决盲选不吃任何修正
- Elo 分母 150→220：纯战力碾压被削弱，弱队靠一手好 BP 有真实翻盘空间

## 战力刻度与体力（联盟一致性）

- **AI 战力=真实阵容结算**：AI 队战力不再用模板静态数字，而是 `aiRosterPower`（五位置最强者求和 × 士气系数 × 教练加成），与玩家 `teamPower` 同刻度。分组按真实战力蛇形落位，玩家的开局种子也等于自己的真实战力
- **AI 教练班底（赛季转会期换帅）**：AI 队教练持久化在 `s.aiCoaches`，初始按原版俱乐部模板落位（豪门名帅/草根平淡）；每个赛季转会期各队有 45% 概率从退役名宿市场挖角更好的教练（**与玩家抢人**），换下的旧帅回流名宿市场可被玩家签。无记录的队按 +6% 平均班底折算（旧版 AI_STAFF 等价值，旧档兼容）
- **挖人变成真战术**：把对面明星谈判签走后，该队阵容重建、战力应声下跌（青训递补）
- **AI 联赛会演化**：AI 选手随赛季年龄成长/衰减，到龄退役由本队青训递补——强队会老化，弱队会重建。成长幅度与玩家刻意不同档：下滑/退役规则与玩家 newSeason 完全一致，黄金期 AI 成长 +2~3/年（玩家 +1/年，但玩家有每日训练/特训额外成长）——联盟年轻选手更快成型，保证玩家始终有可追逐/可挖角的上升期明星
- **体力接入比赛**：体力低于 60 开始衰减（0 体力约 -24%）；BO5/BO7 每小局双方 -8，每日自然恢复 +10、休息 +55。对手阵容体力在**系列赛开始时回满**，衰减只在系列赛内逐局累积、跨系列赛恢复。系列赛越深越考验轮换——替补体力满员就是翻盘资本，BP 台内换替补会显示疲劳差

数值校准结果（`node sim.js`，500 赛季蒙特卡洛，阵容冻结的下限值）：自建新队进季后赛 ~40%、执教 AG 夺冠 ~70%、垫底弱旅进季后赛 ~41%。真人运营（转会/训练/士气管理）会显著高于下限。注：旧版 ~80% 夺冠率是在「对手体力整赛季不恢复」的 bug 下测得的——修复后季后赛对手不再疲惫，AG 夺冠率回落到 ~70%（AI_STAFF 相应 1.10→1.06 校准）；现教练加成已按队差异化（AI_STAFF 常量移除，默认 +6% 等值保留在无记录队），改 `aiCoachBonus` 默认值即可整体调难度。

## 2026-09 董事会与信任度（经营压力与终局）

项目里第一个**可以输**的机制。此前工资帽、资金为负、亚运抽人都在制造压力，但没有一条能让玩家离场，玩到第三个赛季后就成了纯堆积、没有决策张力。

- **赛季 KPI**：每赛季初董事会下发目标——**赛季末年度积分排名进前 N**。N 由上年名次决定（上年前 4→保前 4；前 8→保前 8；其余→保前 12）；首年没有历史名次，按分组档位定（S 组→前 4 / A 组→前 8 / B 组→前 12）
- **信任度结算**（`boardSettle`，挂在 `finishAnnual` 的年终结算上、`newSeason` 之前，此时 `s.season` 还是刚结束那年）：达成 +12；未达成按差距扣（超出名次 ×1.5，下限 −8、上限 −30）；年内每拿一个冠军额外 +6。单赛季增幅封顶 +20，信任度恒在 0~100
- **干预与放权**（`boardApplyEffect`，下赛季生效）：信任 ≤24 → 董事会介入、工资帽压缩 10%；信任 ≥80 → 追加运营预算 +800 万
- **终局**：信任度归零，或连续 3 个赛季未达成且信任 ≤24 → 董事会解约。俱乐部页出现解约结算（执教年数 / 冠军数 / 最佳年度积分名次 / 成就进度），只能重新开始
- **软终局实现（关键约束）**：下课**不阻塞** `nextDay` / `startMatch` / `startCup` 等底层推进函数——平衡门禁（`sim` / `sim-quick` / `fuzz`）直接调用这些函数，硬守卫会让门禁再也测不出真实数值、失去意义。终局走 UI 层入口包装（`uiNextDay` / `uiStartMatch` / `uiStartCup` / `uiSkipTransfer` / `uiEndPreseason`，统一过 `boardLocked()`），底层引擎保持可驱动
- **存档**：`SAVE_VERSION` 3→4，旧档经迁移链自动补出 `board`（信任度默认 60）与 `managerCareer`。存储键名仍是 `esport_manager_save_v3`——改键名会让旧档直接"消失"，结构升级靠迁移链完成
- **成就 2 项**：董事会宠儿（信任度 ≥90）、力挽狂澜（信任度跌破 25 后回到 60）
- 回归用例 `tests/verify-board.js`：KPI 下发 / 达成与未达成结算 / 上下限边界 / 两种下课条件 / 不该误触发 / 干预与放权 / **软终局（UI 拦截而引擎可驱动）** / 面板两态渲染 / v3 旧档迁移 / `annualRank` 与 `myAnnualRank` 语义区分（同名前车之鉴：静态审计当场抓到重复定义）

## 2026-09 粉丝与商业闭环

此前三条线互不相干：选手人气只影响代言、赞助商是"钱够就能升级"、门票只出现在随机事件文案里——打得烂打得好的商业收入几乎一样。现在接成一个环：**成绩 → 粉丝 → 商业收入 → 更强的阵容**。

- **粉丝（`s.fans`，单位万）从哪来**：开档按阵容人气定起点（自建底子低、执教豪门起点高）；每赛段收官按阵容人气 + 名次加成（夺冠 +8 / 亚军 +5 / 进季后赛 +2 / 止步只有人气基本盘）；年总是全年最大曝光（冠军 +25 / 亚军 +12 / 其余 +6）
- **粉丝到哪去**（三处同时生效，共用 `FAN_CAP=600` 万封顶，防极端值把日流水顶穿）
  - 赞助商升级**门槛**：本地电竞馆 20 万 / 全国连锁外设 80 万 / 国际大厂冠名 200 万（钱够但粉丝不够也升不了，面板会显示"还差多少粉"）
  - 赞助每日流水随粉丝上浮（`fanMul(s,500)`）+ 门票/周边日流水（固定系数 × 粉丝）
  - 代言收入 × `fanMul(s,300)`（人气变现随粉丝翻倍）
- **里程碑引导**：粉丝跨过 20/80/200 万时事件日志会提示"可以洽谈哪一级赞助商"，把"涨粉"和"该去升级赞助"连起来
- `dailyCommercialIncome(s)` 抽成纯函数（赞助 + 门票），便于精确断言、也避免断言被随机事件污染

## 2026-09 更衣室（出场时间 / 队长）

替补此前只是"伤停保险"，坐多久的板凳都毫无怨言。现在替补是**有情绪的人**，而依据只有一条玩家能预期的规则：**出场差距**。

## 2026-09 战术板 / 版本大改 / K甲下放

三个玩法深度向系统，共同点：**都只作用于玩家主动选择的路径，不动物价与赛制公式**——平衡门禁的模拟不触发它们，数值体系保持原样。

### 战术板（系列赛倾向）

选战术 = **改变四维在战力里的权重**（总和恒 1）：`playerPower` 的权重向量由 `tacticWeights()` 提供，玩家设置 `S.tacticW` 后即生效，阵容页"总战力"实时反映——没有"最优战术"，只有"最适合你阵容的战术"。

| 战术 | 倾向 | 克制 |
|---|---|---|
| 均衡运营 | 标准 0.25/0.25/0.30/0.20 | — |
| 运营拉扯 | farm .40 | 克制心理博弈 |
| 团战致胜 | team .45 | 克制运营拉扯 |
| 线优压制 | lane .42 | 克制团战致胜 |
| 心理博弈 | mind .38 | 克制线优压制 |

克制 ±3% 只在比赛模拟处结算（`match.js` 唯一战力点），对手战术每场随机懒生成并缓存（同一场系列赛不变），赛前页显示双方战术与克制结果。门禁与 AI 对局不设置战术 → 数值不受影响。

### 赛季版本大改

每年 `newSeason` 时随机两名英雄一加强一削弱（`s.patch` 记录赛季），持有者的四维 ±2（下限/上限照旧）——绝活选手的身价与 BP 优先级随版本浮动，逼你每年重新评估阵容。`applySeasonPatch(s, upN, downN)` 支持显式指定英雄（测试与"策划指定版本"用）。

### K甲下放（青训练级）

替补/青训可**下放 K甲 30 天**：不占首发、不计出场、`swapPlayer` 拦截，归队时两项属性各 +2~4（`p.kjiaGain` 累计）。解决"青训成长太干"——培养有了第三条路（训练 / 比赛 / 外派练级）。

- **成就 2 项**：战术大师（非均衡战术夺冠）、练级成功（下放归队累计成长 ≥5 点）
- 回归用例 `tests/verify-tactics.js`：战术表闭合性（权重和=1、克制不自指悬空）／权重真实生效（团战手/对线手反向变化、撤销复原）／克制 ±3% 且同系列赛稳定／版本增减幅与记录／K甲下放全链路（离队首发→换人拦截→倒计时→归队成长）／成就正反例／面板两处
