# 王者电竞经理 · KPL 篇（重构版）

LOL 电竞经理式的 KPL 俱乐部经营游戏：签约/转会谈判、训练青训、联赛征程、真实 KPL 两段式 BP。

> **声明**：本项目为粉丝自制的**非官方同人作品**，仅供学习交流，与腾讯《王者荣耀》、KPL 联盟及各俱乐部官方均无关联。游戏内选手/战队信息基于公开赛事资料整理，数值、玩法与文案均为原创虚构设计。请勿用于任何商业用途；如内容涉及侵权，联系即删。

## 项目定位与边界

**纯前端单文件同人游戏**：无后端、无数据库、无网络请求，存档在浏览器 localStorage（3 槽）。

- ✅ 本项目范围：本地把玩、学习/演示、二次开发模板
- ❌ 不在范围：线上赛事平台、多人联机、服务端存档——这些需要另行设计后端，本项目不提供
- 🌐 在线演示：`Dockerfile`（nginx 静态站）把 game.html 挂到网上；`npm run build` 后可直接部署
- 🔄 CI：push/PR 自动跑全量测试（`.github/workflows/ci.yml`），并校验构建产物与 src 一致

## 怎么玩

双击打开 **`game.html`**（构建好的单文件版，本地存档在浏览器 localStorage，3 个存档槽）。

## 已知限制（产品特性，非 bug）

- **存档存浏览器 localStorage**：换浏览器、清缓存、无痕模式都会丢进度。建议定期在「存档管理」里点「📤 复制导出」备份存档代码（存到本地文件/收藏夹），换设备/清缓存后「📥 导入」即可恢复。
- **无云端存档**：纯本地单机游戏，不做账号、不联网、不上传任何数据；跨设备同步不在本项目范围。
- **单机无网络请求**：游戏运行期间不发任何网络请求，无埋点、无遥测。

## 设计系统 v3 「NEON ARENA」

- **观感**：电竞转播 HUD——暗夜蓝底（网格纹理 + 霓虹辉光点缀）、切角几何（clip-path 斜切面板/按钮/标签）、青#00e5ff 主色 + 紫#8b5cff 次强调、金=仅奖赏
- **发光**：主按钮/导航/比分用 drop-shadow/box-shadow 辉光；面板顶部青→紫渐变发丝线；弹窗四角 HUD 括号
- **字体**：数字/拉丁用 Bahnschrift（DIN 风、Windows 自带离线可用），中文回退雅黑；数字全部 tabular-nums
- **图标**：`ic(name,size)` 统一细线 SVG；位置单字徽章；选手卡左侧霓虹色条按**总值色阶**实时映射（总值 90+ 金色辉光 / 80+ 蓝 / 其余灰蓝）
- **动效系统**（v3.2）：全局 150ms 微交互 + 250ms 转场 + ease-out 曲线；卡片悬浮抬升+辉光、SSR 金卡呼吸辉光、进度条扫光、页面/弹窗/toast 动效；**数字滚动**（资金/战力平滑滚数）、**选手卡 3D 倾斜**（仅指针设备）、**BP 台盖章式填充+选人闪光**、**首访进场动画**（logo 聚拢→展开→淡出）、**WebAudio 合成音效**（点击/胜负/签约，🔊 可开关）；无障碍降级（`prefers-reduced-motion` 自动关闭）
- **BP 台**：红蓝方霓虹顶条 + 菱形阵营点 + 金色进度条，赛事转播观感
- **页面结构**：七页导航，每页只干一件事——俱乐部（比赛/今日行动/主教练）、阵容（首发/替补/羁绊/总身价）、转会（市场/谈判）、训练（训练/青训营/位置改造）、联赛、联盟（18队战队总览/点击看任意队完整阵容/总值·身价·人气·新星四大选手榜/赛季最佳阵容一阵二阵）、经营（赞助商/工资帽/荣誉室/比赛复盘）；面板保留点标题折叠能力，默认全部展开
- 类名与 v2 完全兼容；`:root` 补了 `--cyan/--card2` 别名（历史内联样式引用）

## KPL BP 赛制（已按官方规则实现）

每局 18 手，两段式征召：

| 阶段 | 顺序 |
|---|---|
| ① 第一轮 BAN | 蓝1 → 红1 → 蓝1 → 红1（各2个） |
| ② 第一轮 PICK | 蓝1 → 红2 → 蓝2 → 红1（各3人） |
| ③ 第二轮 BAN | 红1 → 蓝1 → 红1 → 蓝1（再各2，共4） |
| ④ 第二轮 PICK | 红1 → 蓝2 → 红1（各2，满5人） |

- 系列赛全局 BP：己方用过的英雄本系列赛不能再选
- BO7 战至 3:3 进第 7 局「巅峰对决」：无 BAN、双方盲选、不受全局 BP 限制
- 第 2-6 局败方选边；蓝方先 ban 先选，红方后手 counter（+2% 战力）

## 比赛流程：转会期 → 赛前准备 → BP → 比赛

**赛前转会期（开局/每个新赛季先组队，再开赛）**：创建战队或开启新赛季后先进 **7 天转会期**——落地页就是转会市场，可买断其他俱乐部选手、直签自由球员、挂牌出售、谈判教练；转会期内市场刷新免费（每日首次）、顶星（总值 90+）供给增加，每天可训练/休息后推进一天。俱乐部页显示转会期面板（倒计时 + 首发预览），**转会期内不能开赛**；天数用完自动开始联赛，也可随时点「结束转会期 · 开始赛季」提前开打。转会期结束会校验五个位置都有人（缺人会拦截）。

**卖人也是谈判（与买方对称）**：点「💰 出售」不再是一口价秒卖，而是开启竞价谈判——按总值/人气生成 1~3 家意向俱乐部（豪门预算更足），各自开价；你可以接受、逐轮递交心理要价（要价≤预算即成交、接近预算给最终报价、太高吓跑买家），三轮定生死；黄金期溢价、临近退役打折、人气加成。「回收商」按原一口价永远兜底，低总值选手无人问津也能清仓。挂牌等 AI 报价的被动路径保留。**转售保护**：所有买入路径（自由市场/买断谈判/直签）都会记录买入价，新援打满 5 场比赛前，卖方报价被压在买入价九折内——低买高卖的倒卖套利必亏，让他上场才能卖出真实身价。

**身价随比赛表现浮动**：每局为全体首发生成 KDA（胜负修正），滚动计入表现系数（EMA，均衡值=100×近期平均表现，区间 70%~150%，MVP 额外 +3）。表现系数直接乘进身价——🔥火热最高 +50%、❄️低迷最低 -30%，选手卡/阵容页总身价/选手档案/卖方谈判全部实时显示；档案还记录出场数与场均 KDA。低买练级高卖成为正式玩法：淘新人→让他打出生价→高价出售。

**赛前准备（每场比赛前）**：点开赛先弹赛前准备——调整首发（同位置换替补）、查看对手情报（各位置最强点=🔥，BAN 优先目标）、赛前预估胜率；确认后进 BP 台。BP 台内可「⇄ 换替补」不打断进度，英雄池耗尽也直接换人不用退出。

**有效战力结算（BP 决定胜负的核心）**：比赛模拟不再只吃面板战力，BP 每一步都折算进双方有效战力，BP 台顶部实时显示双方有效战力与预测胜率：

- 我方 BAN 掉「对方池内英雄」每个 **-2%**（BAN 空气仅 -0.5%，别乱 BAN）
- 对方 BAN 我方首发池内英雄每个我方 **-1%**（叠加被迫换人的熟练度损失）
- 对方每选一个版本强势（🔥）英雄 +2%（我方由英雄加成内置）
- 红方后手 counter +2%；巅峰对决盲选不吃任何修正
- Elo 分母 150→220：纯战力碾压被削弱，弱队靠一手好 BP 有真实翻盘空间

## 战力刻度与体力（联盟一致性）

- **AI 战力=真实阵容结算**：AI 队战力不再用模板静态数字，而是 `aiRosterPower`（五位置最强者求和 × 士气系数 × 教练加成），与玩家 `teamPower` 同刻度。分组按真实战力蛇形落位，玩家的开局种子也等于自己的真实战力
- **AI 教练班底（赛季转会期换帅）**：AI 队教练持久化在 `s.aiCoaches`，初始按原版俱乐部模板落位（豪门名帅/草根平淡）；每个赛季转会期各队有 45% 概率从退役名宿市场挖角更好的教练（**与玩家抢人**），换下的旧帅回流名宿市场可被玩家签。无记录的队按 +6% 平均班底折算（旧版 AI_STAFF 等价值，旧档兼容）
- **挖人变成真战术**：把对面明星谈判签走后，该队阵容重建、战力应声下跌（青训递补）
- **AI 联赛会演化**：AI 选手随赛季年龄成长/衰减（与玩家 newSeason 同规则），到龄退役由本队青训递补——强队会老化，弱队会重建
- **体力接入比赛**：体力低于 60 开始衰减（0 体力约 -24%）；BO5/BO7 每小局双方 -8，每日自然恢复 +10、休息 +55。对手阵容体力在**系列赛开始时回满**，衰减只在系列赛内逐局累积、跨系列赛恢复。系列赛越深越考验轮换——替补体力满员就是翻盘资本，BP 台内换替补会显示疲劳差

数值校准结果（`node sim.js`，500 赛季蒙特卡洛，阵容冻结的下限值）：自建新队进季后赛 ~40%、执教 AG 夺冠 ~70%、垫底弱旅进季后赛 ~41%。真人运营（转会/训练/士气管理）会显著高于下限。注：旧版 ~80% 夺冠率是在「对手体力整赛季不恢复」的 bug 下测得的——修复后季后赛对手不再疲惫，AG 夺冠率回落到 ~70%（AI_STAFF 相应 1.10→1.06 校准）；现教练加成已按队差异化（AI_STAFF 常量移除，默认 +6% 等值保留在无记录队），改 `aiCoachBonus` 默认值即可整体调难度。

## 年度赛历（2026 赛制）

一年完整 KPL 赛历，四个赛段依次推进（赛季结束按钮自动衔接）：

1. **春季赛**：18 队 S/A/B 三轮循环 + 卡位赛 + 季后赛双败（原赛制），冠军年度积分 +100
2. **挑战者杯**（春赛后，32 队八大赛道）：18 KPL 全员 + 14 挑战者（K甲/全国大赛/青训/高校/职工/主播/全球赛道虚拟队，选手 def 动态生成可正常 BP）→ 单败 32→16（BO5）→16→8（BO7，春冠/春亚种子分半区）→ 8 强双败（BO7）→ 决赛 **BO9**（第 9 局巅峰对决）；低赛道队对 KPL 有「挑战者的祝福」+5% 战力；冠军 300 万 + 年总积分 85 + FMVP
3. **EWC 电竞世界杯**（利雅得，夏季休赛期）：春季赛冠亚军直邀（冠军=KPL 名额/亚军=英雄亚冠 ACL 名额）+ 6 支海外劲旅 → 8 强 BO7 单败；冠军 540 万（75 万美元）并评 FMVP；未晋级自动观赛补完
4. **夏季赛**：同春季赛制，年中转会期 7 天（不做年龄/合同结算），冠军 +120 积分
5. **KPL 年度总决赛**：年度积分前 12 入围（官方积分表：春 100/80/60/40/20/10/5，挑杯 85/60/40/20/10，夏 120/100/80/50/30/20/10）→ 擂台赛（大师组×精英组 组外单循环 BO5，每队 6 场）→ 突围赛（大师5/6+精英2-5，6 队 BO7 单败）→ 淘汰赛（8 强 BO7 双败），冠军捧圣龙杯 +800 万

**FMVP 名人堂**：春/夏/EWC/年总每个决赛评出冠军队最有价值选手（总决赛各局 MVP 累计优先），人气 +10、身价 +8，经营页荣誉室展示历届。连冠判定改为按时间序（一年两冠）。

**挂牌撤牌修复**：有 AI 报价时也可撤牌（报价一并作废）；阵容页已挂牌选手显示「↩ 撤牌」按钮。

## 相比旧版的改动

- **稀有度退场，FC26 式总值（OVR）**：删除 R/SR/SSR 标签与整张查表定价——选手唯一评价是 `overall()` 按位置加权四维实时计算的总值（0-99），训练/年龄/表现即时反映在数字上；身价、周薪、签约费、市场档位、意向俱乐部数全部由总值曲线出（顶星≈260万 / 主力≈130万 / 轮换≈55万锚位不变）；选手池手写的 `base` 成为选手真实评级（清融 92、一诺 92 一目了然），青训生练出来总值自然涨、自然卖上价；退役转教练/主播改看生涯成就与总值。卡面色阶保留但按实时总值映射，旧存档免迁移（选手总值即时补算，教练 rarity→rating 自动升级）
- **王朝反制（连冠≥2 自动触发）**：现实里反制王朝的三板斧——①对阵连冠队伍，研究方有效战力 +2%/连冠季（上限 +6%，AI 互赛同规则，联赛会自动遏制超级王朝）②连冠队伍工资帽成长减半（+15→+7万/季，豪华阵容越留越贵）③开启新赛季时「版本针对」核心选手（属性/士气/状态受挫，力度随连冠次数加码）。联盟页战队总览给连冠队伍挂 🏆 标记；玩家提前出局的赛季现在会补完联盟赛程、照常产生冠军（连冠链条不断档）
